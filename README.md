# Dimasik Launcher

[Скачать последнюю версию](https://github.com/sashaust488-netizen/dimasik-launcher-releases/releases/latest/download/Dimasik-Launcher.exe) · [Все выпуски](https://github.com/sashaust488-netizen/dimasik-launcher-releases/releases)

Скачайте `Dimasik-Launcher.exe` и запустите его. Отдельно скачивать DLL не нужно.

Лаунчер проверяет обновления при запуске и устанавливает их автоматически, когда игра закрыта. Проверить вручную можно в настройках → «Обновления». Дата выпуска и список изменений доступны в лаунчере.

Если старая версия показывает ошибку проверки обновлений, скачайте версию 1.22.2 вручную один раз. Следующие версии будут обновляться через лаунчер.
